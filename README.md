# Weather Forecast Application

A responsive weather app built with React, Bootstrap and the OpenWeather API.

## Features
- Search weather by city name
- Current temperature and conditions
- Humidity and wind speed
- 5-day forecast

## Tech Stack
ReactJS, JavaScript, HTML, CSS, Bootstrap, OpenWeather API

## Run Locally
1. Clone the repo
2. Run `npm install`
3. Create a `.env` file with `VITE_WEATHER_KEY=your_api_key`
4. Run `npm run dev`
